📥 Import des clients
Importe ton export CSV Shopify ou ajoute un client manuellement. L'app lira le nom, prénom, email et type de corail.
Export Shopify : Admin → Commandes → Exporter → CSV.
Colonnes nécessaires : Billing First Name, Billing Last Name, Email, et le champ personnalisé du type de corail.

📧 Connexion Gmail
Autorise l'accès à sango.restoration@gmail.com pour envoyer les certificats. Google va te demander de confirmer les permissions.
Comment ça fonctionne :
Clique sur "Connecter Gmail" → une fenêtre Google s'ouvre → connecte-toi avec sango.restoration@gmail.com → autorise l'envoi d'emails → c'est fait ✓
✉️
sango.restoration@gmail.com ✓ Compte connecté — prêt à envoyer
✅
✍️ Contenu de l'email
Personnalise le message. Les variables {prenom}, {nom} et {type} seront remplacées automatiquement.
